#Verificador de Palíndromos

Um palíndromo é uma palavra ou frase que se lê da mesma forma de trás para frente (desconsiderando espaços e maiúsculas), como "arara" ou "reviver" ou “socorram me subi no ônibus em Marrocos”.
    Crie um campo de texto (<input>) onde o usuário possa digitar uma palavra.
    Adicione um botão "Verificar" que, ao ser clicado, leia o texto digitado e mostre na tela uma mensagem informando se aquela palavra é ou não um palíndromo.
