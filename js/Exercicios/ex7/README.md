#Relógio Digital em Tempo Real

Desenvolva uma página com um elemento visual de destaque (<h2> ou <div>) que funcione como um relógio digital.
    Use o temporizador contínuo para atualizar a tela a cada 1 segundo.
    O relógio deve exibir as horas, minutos e segundos atuais no formato HH:MM:SS (ex: 14:35:08).

Dica: Utilize o objeto Date do JavaScript para capturar o horário do sistema (getHours, getMinutes, getSeconds).
